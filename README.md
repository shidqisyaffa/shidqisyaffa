## ⚡ Engineering Profile

I am a Computer Science student and a project-driven developer. I enjoy building applications to understand how they work under the hood. For me, creating hands-on projects is the best way to explore new technologies, test engineering concepts, and grow my programming skills.

### 🔬 Core Interests
- **Network Programming & Concurrency** — Building serverless peer-to-peer applications, TCP/UDP client-server scripts, and chat systems to learn the fundamentals of network protocols, multi-threading, and socket communication.
- **Artificial Intelligence & Local ML** — Experimenting with generative models (like GANs and WGAN-GP), Natural Language Processing (NLP) sentiment analysis, and text generation to explore the practical applications of deep learning.
- **Parallel Computing & Graph Algorithms** — Exploring how to optimize intensive calculations, such as pathfinding and traffic flow simulation, using C++ with OpenMP and parallel JavaScript.
- **Desktop & GUI Applications** — Wrapping command-line tools, diagnostics scanners, and scripts in clean, modern dark-themed desktop interfaces using Python (CustomTkinter) and Java.

### 🛡️ Software Engineering Principles
- **Keep it Simple & Functional** — I focus on building the simplest, most practical solution that works before introducing unnecessary complexity.
- **Write Readable & Modular Code** — I structure my code cleanly so that it is easy to read, debug, and maintain, even months after I built the project.
- **Optimize Based on Need** — I focus on performance improvements (like multi-threading or parallelization) when there is a clear, measurable bottleneck to solve.
- **Value Hands-On Exploration** — I treat every bug and challenging feature as an opportunity to learn how systems, frameworks, and APIs operate behind the scenes.
